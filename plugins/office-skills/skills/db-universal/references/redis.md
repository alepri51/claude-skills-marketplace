# Redis — особенности

Redis — не реляционка, поэтому `db_schema` и `db_query` здесь не
применимы. Используются отдельные инструменты.

## Ключи по шаблону

```
python scripts/db.py db_keys '{"pattern":"user:*"}' --connection <name>
```

- `pattern` — glob-синтаксис Redis (`*`, `?`, `[abc]`), **не** SQL-LIKE.
- Возвращает максимум 200 ключей. Для больших БД лучше использовать
  более точный шаблон.
- `KEYS` блокирующая команда — на проде нагруженного Redis может
  тормозить. Для исследования структуры — ок, для автоматизации —
  нежелательно.

## Значение по ключу

```
python scripts/db.py db_get '{"key":"user:42"}' --connection <name>
```

Автоопределение типа: `string`, `hash`, `list`, `set`, `zset`.
Для больших коллекций лимиты:
- list → первые 100 элементов
- set → первые 100 элементов
- zset → первые 100 элементов со score

## База (database index)

Redis-база выбирается через `database` в подключении (0–15 по
умолчанию). В `connections.json` — это `database` (не confuse с
MySQL-database).

## Нет table-инспекции

`db_tables` для redis технически возвращает ключи (список).
Если хочется «каталогизировать» — сгруппировать по префиксу вручную.
